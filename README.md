# Simple Tkinter Calculator

A simple desktop calculator built with Python and Tkinter.

## Features
* Standard arithmetic operations (+, -, *, /)
* Division by zero protection
* Decimal point handling

## How to Run
1. **Source Code:** Run `python Calculator.py` (requires Python 3.x).
2. **Standalone App:** Download `Calculator.exe` directly from the [Releases](https://github.com/Dania129/Tkinter_Calculator/releases) page.
